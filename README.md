# CYHY577 · 项目作品集

统一项目入口；各项目保留独立仓库。

网站：https://cyhy577.github.io/

赛博 HUD 风格的单页作品集，所有页面代码、样式、SVG 和交互均在 index.html 中。
使用 Tailwind 浏览器版本、Three.js、GSAP / ScrollTrigger 与 Google Fonts CDN；无 API Key，无付费接口调用。
手机端（宽度小于 768px）及减少动态效果模式不加载 Three.js，使用内嵌 SVG 静态走廊；CDN 或 WebGL 不可用时仍可阅读项目。
环境音默认关闭，用户点击后启用；支持跳过开机动画和键盘导航。
旧版 style.css 已不被当前首页引用。
在 GitHub Pages 选择 main 分支的根目录发布。

新增项目：在 index.html 的 chambers 区域添加 article，填写经过核实的简介及公开仓库链接；不得上传凭据或未授权公开的个人资料。
